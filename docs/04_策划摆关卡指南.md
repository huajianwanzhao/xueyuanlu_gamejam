# 策划摆关卡指南（不用写代码）

你可以在 Godot 编辑器里直接把关卡做出来。**只碰 `levels/` 里的文件**，其他都别动。

## 打开

双击 `D:\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64.exe` → 打开项目 `D:\学院路gamejam` → 在左下「文件系统」里双击 `levels/level_01.tscn`。

## 界面 3 个区域

- **左上 场景树**：这一关里有什么（平台、金币、玩家、终点）。
- **中间 画布**：2D 视图，可以直接拖。滚轮缩放，鼠标中键拖动平移。
- **右侧 检查器**：选中物体后，在这里改它的属性（位置、尺寸）。

## 加一块平台

1. 在左下文件系统找到 `scenes/objects/platform.tscn`；
2. 鼠标拖到中间的画布上松手（或在场景树里右键 Level01 → 「实例化子场景」）；
3. 选中它，在右侧检查器改：
   - `Position`：x 往右、y 往下（屏幕坐标，左上角是 0,0）；
   - `size`：宽度和高度，**改完碰撞体自动跟着变**，不用管碰撞。

> 尺寸建议：高度固定 16 或 32，宽度用 8 的倍数。

## 加金币 / 终点

同样从 `scenes/objects/` 拖 `coin.tscn`、`goal.tscn` 进画布。金币碰到就加分，终点碰到就过关。

## 摆放玩家出生点

拖动场景树里的 `Player`。注意玩家原点在**身体中心**，站地面上时 y 大约 = 地面顶部 - 14。

## 关卡边界

- 画面是 1280×720。x 范围 0–1280，y 范围 0–720。
- 掉到 y > 460 算摔死并重开本关 —— 想让玩家掉下去死，就在地面留缺口。

## 复制与删除

- 复制：`Ctrl + D`
- 删除：`Delete`
- 撤销：`Ctrl + Z`（放心大胆改）

## 测试

- `Ctrl + S` 保存。
- 回主菜单场景（`scenes/main_menu.tscn`）按 **F5** 跑完整游戏。
- **在主菜单按数字键 1 / 2 可以直接从第 N 关开始**（调试用，别删）。

## 加一关

1. 在文件系统里右键 `level_01.tscn` → 复制 → 重命名 `level_03.tscn`；
2. 告诉程序：在 `scripts/autoload/game_manager.gd` 的 `LEVELS` 数组里加一行。

## 手感调参（也可以你来调）

双击 `scenes/player/player.tscn`，选中 Player，右侧检查器里「手感」分组：

| 参数 | 作用 | 调大的效果 |
|---|---|---|
| speed | 移动速度 | 跑得更快 |
| jump_force | 跳跃初速度 | 跳得更高 |
| gravity | 重力 | 下落更快、跳得更矮 |

改完 `Ctrl+S`，F5 立刻能感觉到。**这些不要问程序，自己调。**

## 三条规矩

1. 不要在 `game.tscn` / `player.tscn` / 脚本里改东西——只改 `levels/`。
2. 一次只改一关，改完就保存 + 提交，别攒。
3. 遇到编辑器报错，先截图发群里，不要自己乱点。
