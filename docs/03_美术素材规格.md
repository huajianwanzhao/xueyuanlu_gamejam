# 美术素材规格（给美术，也给你自己）

规格不统一 = 你会花一半时间返工。**开工前把这张表发给美术，让他照着交。**

## 画布

- 游戏视口：**640 × 360**（16:9），像素风。
- 所有素材按 **1 像素 = 1 游戏像素** 画，不要按 1920 宽画完再缩。
- 透明背景用 PNG（带 alpha）。

## 尺寸

| 素材 | 尺寸（px） | 备注 |
|---|---|---|
| 角色 | 16 × 28 | 脚底对齐画布底边；面朝右画，左向程序翻转 |
| 金币/收集物 | 16 × 16 | 居中 |
| 平台/地块 | 16 的倍数，高 16 | 用可平铺的方块，长度在引擎里拉伸 |
| 背景 | 640 × 360 | 可分 2–3 层视差 |
| UI 图标 | 16/24/32 | 统一一套 |
| 标题 Logo | 宽 ≤ 480 | 高不超过 120 |

## 命名与目录

```
assets/sprites/player/idle_01.png, run_01.png, jump_01.png
assets/sprites/objects/coin.png, spike.png
assets/sprites/tiles/ground.png
assets/sprites/ui/button.png
assets/audio/sfx/coin.wav, jump.wav, die.wav, win.wav
assets/audio/music/bgm.ogg
```

- 全小写，下划线，不要中文名，不要空格。
- 动画帧用 `_01 _02 _03` 结尾，程序好批量导入。

## 音频

- 音效：**wav**，16bit，44.1kHz，单声道，≤ 1 秒，音量归一化到 -3dB。
- 音乐：**ogg**，循环点做好，≤ 2 分钟。
- 文件名 = 代码里的名字（`coin.wav` → `AudioManager.play_sfx("coin")`）。

## 交付节奏（很重要）

1. **D3 前**：占位图（纯色块/剪影都行）。没有占位图程序就不开工，这是浪费。
2. **D6 前**：能看的第一版正式图（不要求精致）。
3. **D10 前**：全部替换完成。
4. **D13 前**：只修像素级瑕疵。
