# 一页纸 GDD（20 分钟填完，填完就冻结）

> 规则：**只允许一页**。写不下的想法就是不该做的想法。

## 1. 一句话

> 玩家扮演 ______，通过 ______（唯一动词），达成 ______。

例：玩家扮演一只漏气的气球，通过**放气冲刺**，在燃料耗尽前飞到终点。

## 2. 核心循环（30 秒内能说清）

1. 玩家看到 ______
2. 做一个 ______ 的操作
3. 得到 ______ 的反馈
4. 难度/风险 ______ 上升

## 5. 内容量（按这个砍）

- 关卡数：____ 个（新手建议 3–5）
- 敌人/障碍种类：____ 种（新手建议 ≤ 2）
- 需要新写的系统：____ 个（**超过 1 个就危险**）
