# 导出与提交清单

## 一、第一次导出前（赛前必做，一次就好）

1. 打开 Godot → 菜单 **编辑器 → 管理导出模板 → 下载并安装**（版本必须和引擎一致：4.7.2）。
2. 关闭并重开编辑器。
3. 菜单 **项目 → 导出**，应该能看到预设 **Web**（模板里已经配好）。

## 二、导出 Web 版

1. **项目 → 导出 → Web → 导出项目**；
2. 路径填 `build/web/index.html`（`build/` 已在 .gitignore 里，不会进仓库）；
3. 得到 `build/web/` 文件夹（含 index.html、.wasm、.pck）。

**本地测试**：在 `build/web` 目录里开一个本地服务器（直接双击 index.html 不行）：

```powershell
cd D:\学院路gamejam\build\web
python -m http.server 8000
```

浏览器打开 `http://localhost:8000` 试玩。

## 三、WebGL 中文变方块？必须修

模板的字体是**系统字体**，桌面端正常，网页端找不到系统字体就会显示方块。

修法（10 分钟）：

1. 下一个开源中文字体，例如 **思源黑体 Noto Sans SC**（Google Fonts 免费），取 `.ttf` 或 `.otf`（体积小的子集版更好）。
2. 放进项目 `assets/fonts/`，比如 `assets/fonts/NotoSansSC-Regular.ttf`。
3. 双击 `ui/theme.tres`，在检查器里把 **Default Font** 换成这个字体文件。
4. 重新导出，网页里验证中文显示正常。

> 字体文件会让包体变大（思源黑体约 10MB）。时间紧就用「阿里巴巴普惠体」或只保留常用字的子集。

## 四、上传 itch.io

1. 新建项目 → Kind of project 选 **HTML**。
2. 把 `build/web` 里的所有文件打成 **zip**（zip 根目录里必须直接是 index.html）。
3. 上传 zip，勾选 **This file will be played in the browser**。
4. 设置视口尺寸 1280×720，勾选 **Fullscreen button**。
5. 保存后点 **View page** 实际玩一遍。

## 五、提交前 30 分钟检查表

- [ ] 网页版能玩（不是只有本地能玩）
- [ ] 中文全部正常显示
- [ ] 音效能听到（第一次点击后才会响，属正常）
- [ ] 有「开始游戏」按钮（音频需要用户点击才能播）
- [ ] 从第一关玩到通关，全程无卡死
- [ ] 失败后能重开，不会卡在黑屏
- [ ] 页面写了：操作说明、制作人员、素材来源
- [ ] 截图 3 张 + 1 个 GIF 已上传
- [ ] **提前 3–5 小时点提交**，留出翻车时间

## 六、常见翻车与原因

| 现象 | 原因 | 修法 |
|---|---|---|
| 网页黑屏 | 用了 Forward+ 渲染器 | 项目设置里渲染方法改回 GL Compatibility |
| 中文方块 | 系统字体没导出 | 按上面第三节换 ttf 字体 |
| 本地能玩，上传后黑屏 | zip 里多套了一层文件夹 | zip 根目录必须直接是 index.html |
| 没有声音 | 浏览器要求先点击 | 确保有开始按钮，别自动播放 |
| 导出按钮是灰的 | 没装导出模板 | 编辑器 → 管理导出模板 → 下载安装 |
| 上传失败/太大 | 音乐文件太大 | 音乐转 ogg / 降比特率，别放 wav 长音乐 |

## 七、每天都要做的「保险」

- 每天至少成功导出一次 Web 包，自己玩 2 分钟。
- 每天 `git push`。
- 把最终可玩的包**另外复制一份**到项目外（U 盘/网盘），别只放在 build 里。
